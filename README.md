# Personal Space — Premium Liquid Glass

Versi premium menambahkan visual layer terpisah melalui `premium.css`, sehingga data di `index.html` tetap mudah diedit. Perubahan utama:

- layered glass surfaces dengan highlight internal, border specular, saturasi, dan blur yang lebih dekat ke Apple Liquid Glass;
- ambient light yang bergerak pelan, entrance animation, hover depth, dan reduced-motion support;
- navigation pill yang lebih polished, mobile menu yang lebih halus, serta gallery/lightbox yang lebih immersive;
- visual tetap vanilla HTML/CSS/JS dan GitHub Pages friendly.

Edit konten di `index.html`. Ganti video di `<source>`, gambar poster di `styles.css`, dan gambar gallery pada CSS variable masing-masing. Untuk musik, isi `audio.src` di `script.js`; autoplay bersuara tetap membutuhkan interaksi pengguna karena aturan browser.
